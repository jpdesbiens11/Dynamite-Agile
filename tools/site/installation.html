Installer DynamiteAgile

Cinq étapes, de haut en bas. Chaque commande se copie d'un clic, et une étiquette dit où la coller : sur votre ordinateur ou sur le serveur.

{{LATEST}}
0 étape faite

  1. 1 Linux ou Windows ?

    Où l'outil va-t-il tourner pour votre équipe ?

    Besoin d'aide ? Un assistant IA vous guide pas à pas

    Ouvrez Claude (ou votre assistant habituel) et collez-lui ce message : il lit cette page et vous guide une commande à la fois. Collez-lui ensuite ce que l'écran affiche, surtout un message en rouge. Pour un serveur qui n'est pas vide (d'autres applications, Docker…), c'est lui qui adapte la procédure.

    Ne lui donnez jamais un mot de passe ni une clé privée : ils se tapent seulement dans le terminal.

  2. 2 Prenez un serveur (VPS)

    Un serveur vide sous Ubuntu 24.04 : 1 processeur et 1 Go de mémoire suffisent. Choisissez un hébergeur :

    1. Sur hostinger.com, prenez un forfait VPS (le plus petit suffit).
    2. hPanel → VPS → OS & Panel : Ubuntu 24.04, le système seul (sans panneau ni application).
    3. Page Overview : notez l'adresse IP ; Root password → Change pour choisir le mot de passe.
    4. Security → Firewall : s'il y a des règles, autorisez les ports 22, 80 et 443.
    1. Sur oracle.com/cloud/free, créez un compte « Free Tier ».
    2. Compute → Instances → Create instance : image Canonical Ubuntu 24.04, forme VM.Standard.A1.Flex (ou VM.Standard.E2.1.Micro si l'autre est indisponible), toutes deux « Always Free ».
    3. À la création, Save private key : gardez ce fichier .key, il remplace le mot de passe.
    4. Page de l'instance → Subnet → Security List → Add Ingress Rules : source 0.0.0.0/0, TCP, ports 80 puis 443. Notez l'adresse IP publique.
    1. Sur digitalocean.com (étudiants : activez d'abord le GitHub Student Developer Pack), Create → Droplets.
    2. Image Ubuntu 24.04, le plus petit forfait, authentification par mot de passe (choisissez-le).
    3. Notez l'adresse IP du Droplet. Aucun pare-feu à régler : l'installation s'en charge.

  3. 3 Donnez-lui une adresse web

    L'équipe ouvrira l'outil par une adresse comme atelier.mon-domaine.ca, en HTTPS. Dans le gestionnaire DNS du domaine, créez un enregistrement A : nom atelier, valeur 203.0.113.10.

    Pas de nom de domaine ?
    • Achetez-en un (une dizaine de dollars par an), ou utilisez celui offert par votre forfait Hostinger.
    • Gratuit : un sous-domaine DuckDNS (mon-equipe.duckdns.org) : connectez-vous, choisissez le nom, collez l'adresse IP, update ip.

    Vérifiez quelques minutes plus tard : nslookup atelier.mon-domaine.ca dans un terminal doit répondre 203.0.113.10.

  4. 4 Connectez-vous au serveur

    Ouvrez un terminal (Windows : Terminal ; macOS : Terminal) et tapez :

    ssh root@203.0.113.10
    ssh -i ~/Downloads/ssh-key.key ubuntu@203.0.113.10

    Répondez yes à la première connexion, puis tapez le mot de passe (rien ne s'affiche, c'est normal). La ligne commence par root@… ou ubuntu@… : vous êtes sur le serveur. Sans terminal, le bouton Console de l'hébergeur fait la même chose.

  5. 5 Installez, en une commande

    curl -fsSL {{SITE_URL}}/install.sh | sudo bash -s -- atelier.mon-domaine.ca moi@exemple.ca

    Deux à cinq minutes. La fin affiche == 7/7 C'est installé, l'adresse et le mot de passe temporaire du compte admin. Ouvrez https://atelier.mon-domaine.ca, connectez-vous, choisissez votre mot de passe, puis ⚙ Admin → Spaces → Commencer pour créer le Space de votre produit avec l'IA.

    Ce que fait la commande

    Elle installe Python, git, certbot et le pare-feu, récupère le code dans /opt/dynamite_agile, obtient le certificat HTTPS (renouvelé tout seul) et démarre le service. Pour mettre à jour plus tard : ⚙ Admin → Update, ou relancez la même commande ; les données restent. Le script est lisible ici : deploy/install.sh.

  6. 2 Choisissez le PC de l'équipe

    Windows 10, 11 ou Server, branché au réseau de l'équipe et toujours allumé (Paramètres → Système → Alimentation : mise en veille Jamais). Le réseau doit être Privé (Paramètres → Réseau et Internet → Propriétés).

  7. 3 Ouvrez PowerShell en administrateur

    Sur ce PC : Win + X → Terminal (admin), puis Oui.

    La ligne commence par PS C:\WINDOWS\system32>.

  8. 4 Installez, en une commande

    irm {{SITE_URL}}/install.ps1 -OutFile $env:TEMP\install-dynamite.ps1; powershell -ExecutionPolicy Bypass -File $env:TEMP\install-dynamite.ps1

    Cinq à dix minutes. La fin affiche == C'est installé, l'adresse (https://nom-du-pc) et le mot de passe temporaire du compte admin.

    Ce que fait la commande

    Elle installe Python et Git, récupère le code dans C:\DynamiteAgile, crée le certificat HTTPS de l'équipe, ouvre le port 443 pour le réseau privé seulement et crée la tâche qui démarre l'outil avec Windows. Le script : deploy/install.ps1.

  9. 5 Ouvrez l'outil sur chaque poste

    Copiez C:\DynamiteAgile\data\tls\partage\ca-dynamite.crt sur chaque poste (clé USB, dossier partagé), puis, sur chaque poste Windows, dans PowerShell, dans le dossier du fichier :

    Import-Certificate -FilePath .\ca-dynamite.crt -CertStoreLocation Cert:\CurrentUser\Root

    Répondez Oui. Ouvrez https://nom-du-pc, compte admin et le mot de passe temporaire, puis ⚙ Admin → Spaces → Commencer. Sur macOS : double-cliquez le fichier → Trousseau → Toujours approuver.

Et ensuite ? Le guide explique chaque module, de MVP0 au lancement. Un message d'erreur ? Voyez Si quelque chose bloque, ou collez-le à votre assistant IA.
