Installer DynamiteAgile

Cinq étapes, de haut en bas. Chaque commande se copie d'un clic, et une étiquette dit où la coller : sur votre ordinateur ou sur le serveur.

{{LATEST}}

Avant de commencer : d'où faites-vous l'installation ?

L'ordinateur sur lequel vous tapez les commandes (celui où vous lisez cette page). Ce n'est pas forcément celui où l'outil va tourner : ça, c'est l'étape 1. Toutes les commandes « sur votre ordinateur » s'adaptent à ce choix.

0 étape faite

  1. 1 Où l'outil va-t-il tourner ?

    Besoin d'aide ? Un assistant IA vous guide pas à pas

    Ouvrez Claude (ou votre assistant habituel) et collez-lui ce message : il lit cette page et vous guide une commande à la fois. Collez-lui ensuite ce que l'écran affiche, surtout un message en rouge. Pour un serveur qui n'est pas vide (d'autres applications, Docker…) ou sans Internet du tout, c'est lui qui adapte la procédure.

    Ne lui donnez jamais un mot de passe ni une clé privée : ils se tapent seulement dans le terminal.

  2. 2 Prenez un serveur (VPS)

    Un serveur vide sous Ubuntu 24.04 : 1 processeur et 1 Go de mémoire suffisent. Choisissez un hébergeur :

    1. Sur hostinger.com, prenez un forfait VPS (le plus petit suffit).
    2. hPanel → VPS → OS & Panel : Ubuntu 24.04, le système seul (sans panneau ni application).
    3. Page Overview : notez l'adresse IP ; Root password → Change pour choisir le mot de passe.
    4. Security → Firewall : s'il y a des règles, autorisez les ports 22, 80 et 443.
    1. Sur oracle.com/cloud/free, créez un compte « Free Tier ».
    2. Compute → Instances → Create instance : image Canonical Ubuntu 24.04, forme VM.Standard.A1.Flex (ou VM.Standard.E2.1.Micro si l'autre est indisponible), toutes deux « Always Free ».
    3. À la création, Save private key : gardez ce fichier .key dans votre dossier Téléchargements, il remplace le mot de passe.
    4. Page de l'instance → Subnet → Security List → Add Ingress Rules : source 0.0.0.0/0, TCP, ports 80 puis 443. Notez l'adresse IP publique.
    1. Sur digitalocean.com (étudiants : activez d'abord le GitHub Student Developer Pack), Create → Droplets.
    2. Image Ubuntu 24.04, le plus petit forfait, authentification par mot de passe (choisissez-le).
    3. Notez l'adresse IP du Droplet. Aucun pare-feu à régler : l'installation s'en charge.

  3. 3 Donnez-lui une adresse web

    L'équipe ouvrira l'outil par une adresse comme atelier.mon-domaine.ca, en HTTPS. Dans le gestionnaire DNS du domaine, créez un enregistrement A : nom atelier, valeur 203.0.113.10.

    Chez Hostinger, rien à régler : votre VPS a déjà un nom gratuit (hPanel → VPS → Overview → Hostname, ex. srv123456.hstgr.cloud) qui pointe vers son adresse IP. Utilisez-le tel quel, ou avec un mot devant : atelier.srv123456.hstgr.cloud.

    Pas de nom de domaine ?
    • Chez Hostinger : le nom gratuit du VPS, ci-dessus. Ou achetez un domaine (une dizaine de dollars par an).
    • Gratuit : un sous-domaine DuckDNS (mon-equipe.duckdns.org) : connectez-vous, choisissez le nom, collez l'adresse IP, update ip.

    Vérifiez quelques minutes plus tard, dans un terminal () :

    nslookup atelier.mon-domaine.ca

    La réponse doit montrer 203.0.113.10. Sinon, attendez encore un peu.

  4. 4 Connectez-vous au serveur

    Ouvrez un terminal sur votre ordinateur () et tapez :

    ssh root@203.0.113.10

    Une fois, protégez la clé téléchargée (sinon la connexion la refuse) :

    icacls $HOME\Downloads\ssh-key.key /inheritance:r /grant:r "$($env:USERNAME):(R)"
    chmod 600 ~/Downloads/ssh-key.key

    Puis connectez-vous :

    ssh -i $HOME\Downloads\ssh-key.key ubuntu@203.0.113.10
    ssh -i ~/Downloads/ssh-key.key ubuntu@203.0.113.10

    Le fichier porte un autre nom ? Remplacez ssh-key.key par le sien.

    Répondez yes à la première connexion, puis tapez le mot de passe s'il est demandé (rien ne s'affiche, c'est normal). La ligne commence par root@… ou ubuntu@… : vous êtes sur le serveur. Sans terminal, le bouton Console de l'hébergeur fait la même chose.

  5. 5 Installez, en une commande

    curl -fsSL {{SITE_URL}}/install.sh | sudo bash -s -- atelier.mon-domaine.ca moi@exemple.ca

    Deux à cinq minutes. La fin affiche == 7/7 C'est installé, l'adresse et le mot de passe temporaire du compte admin. Ouvrez https://atelier.mon-domaine.ca, connectez-vous, choisissez votre mot de passe, puis ⚙ Admin → Spaces → Commencer pour créer le Space de votre produit avec l'IA.

    Ce que fait la commande

    Elle installe Python, git, certbot et le pare-feu, récupère le code dans /opt/dynamite_agile, obtient le certificat HTTPS (renouvelé tout seul) et démarre le service. Pour mettre à jour plus tard : ⚙ Admin → Update, ou relancez la même commande ; les données restent. Le script est lisible ici : deploy/install.sh.

  6. 2 Choisissez le PC de l'équipe

    Windows 10, 11 ou Server, branché au réseau de l'équipe et toujours allumé (Paramètres → Système → Alimentation : mise en veille Jamais). Le réseau doit être Privé (Paramètres → Réseau et Internet → Propriétés). Internet sert pendant l'installation seulement.

  7. 3 Ouvrez PowerShell en administrateur

    Sur ce PC : Win + X → Terminal (admin), puis Oui.

    La ligne commence par PS C:\WINDOWS\system32>.

  8. 4 Installez, en une commande

    irm {{SITE_URL}}/install.ps1 -OutFile $env:TEMP\install-dynamite.ps1; powershell -ExecutionPolicy Bypass -File $env:TEMP\install-dynamite.ps1

    Cinq à dix minutes. La fin affiche == C'est installé, l'adresse (https://nom-du-pc) et le mot de passe temporaire du compte admin.

    Ce que fait la commande

    Elle installe Python et Git, récupère le code dans C:\DynamiteAgile, crée le certificat HTTPS de l'équipe, ouvre le port 443 pour le réseau privé seulement et crée la tâche qui démarre l'outil avec Windows. Le script : deploy/install.ps1.

  9. 5 Ouvrez l'outil sur chaque poste

    Copiez C:\DynamiteAgile\data\tls\partage\ca-dynamite.crt sur chaque poste (clé USB, dossier partagé), puis, dans le dossier du fichier, faites-lui confiance :

    Import-Certificate -FilePath .\ca-dynamite.crt -CertStoreLocation Cert:\CurrentUser\Root
    sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ca-dynamite.crt
    sudo cp ca-dynamite.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates

    Ouvrez https://nom-du-pc, compte admin et le mot de passe temporaire, puis ⚙ Admin → Spaces → Commencer.

Dès l'installation : le Space DEMO

L'outil s'ouvre sur un seul Space, DEMO : le tour guidé de chaque outil, un bac à sable où tout s'essaie sans risque, les documents de formation et la bibliothèque de référence. Il contient aussi un exemple complet, le Rover : un petit véhicule autonome bâti sur une auto téléguidée tout-terrain, piloté par un Raspberry Pi et une application web, qui ralentit à l'approche d'un obstacle et le contourne lentement. Tous les modules y sont remplis de MVP 0 à MVP 3 : besoins et requirements, Test Base, arbre fonctionnel, structure, pièces, risques et DFMEA, backlog, idéation, Pugh, Kepner-Tregoe, livrables, plan du PDP et des pages qui expliquent chaque décision.

  1. ExplorezDynamite → DEMO → « Rover — accueil du projet » : le guide de lecture dit où regarder, module par module.
  2. Commencez votre projet⚙ Admin → Spaces → Commencer : un assistant IA prépare le Space de votre produit.
  3. Cachez DEMOQuand le vrai projet démarre, ⚙ Admin → Spaces → DEMO → « Cacher pour tous ». La documentation de Help reste accessible.

Et ensuite ? Le guide explique chaque module, de MVP0 au lancement. Un message d'erreur ? Voyez Si quelque chose bloque, ou collez-le à votre assistant IA.
