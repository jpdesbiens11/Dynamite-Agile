Installer Dynamite | Agile

2. Gardez un assistant IA à vos côtés (conseillé)

Ouvrez Claude (ou votre assistant habituel) dans une autre fenêtre et collez-lui ce message avant de commencer : il lit cette procédure et vous guide une commande à la fois. Collez-lui ensuite ce que le terminal affiche, surtout s'il y a un message en rouge.

3. Vos informations

Elles remplissent les commandes ci-dessous. Rien n'est envoyé nulle part : tout reste dans cette page.

0 étape faite
  1. Préparez le serveur Un VPS Linux Ubuntu 24.04 (1 vCPU et 1 Go de mémoire suffisent). Dans le pare-feu du panneau de l'hébergeur, ouvrez les ports 22, 80 et 443.
    Où trouver ça chez Hostinger
    • hPanel → VPS → OS & Panel : système Ubuntu 24.04 (sans application qui occupe les ports 80 ou 443).
    • Page Overview : l'IP du serveur, l'utilisateur SSH root, et Root password → Change pour choisir le mot de passe.
    • Security → Firewall : autorisez 22, 80 et 443.
  2. Pointez le domaine vers le serveur Dans le gestionnaire DNS du domaine, créez un enregistrement A : nom atelier (ou @), valeur 203.0.113.10. Vérifiez quelques minutes plus tard : 
    nslookup atelier.mon-domaine.ca

    Vous devez voir 203.0.113.10 dans la réponse. Sinon, attendez encore un peu.

    Chez Hostinger

    hPanel → Domains → votre domaine → DNS / Nameservers, ou Claim your free domain sur la page du VPS.

  3. Connectez-vous au serveur Ouvrez un terminal (Windows : Terminal ou PowerShell ; macOS : Terminal) et tapez le mot de passe root quand il est demandé (rien ne s'affiche pendant la frappe, c'est normal) : 
    ssh root@203.0.113.10

    La ligne commence maintenant par root@… : vous êtes sur le serveur. À la première connexion, répondez yes. Pas de terminal ? Le bouton Web console du panneau fait la même chose.

  4. Installez, en une commande 
    curl -fsSL {{SITE_URL}}/install.sh | sudo bash -s -- atelier.mon-domaine.ca moi@exemple.ca
    curl -fsSL {{SITE_URL}}/install.sh | sudo bash -s -- --traefik atelier.mon-domaine.ca

    Pas sûr pour Traefik ? La commande le détecte d'elle-même et s'installe derrière lui. Pour mettre à jour plus tard : relancez la même commande, les données restent.

    Deux à cinq minutes. La fin affiche == 7/7 C'est installé, l'adresse à ouvrir et le mot de passe temporaire du compte admin : gardez cette fenêtre ouverte.

    Ce que fait la commande

    Elle récupère le code dans /opt/dynamite_agile, installe Python, git, certbot et le pare-feu, crée l'utilisateur système dynamite, obtient le certificat HTTPS (renouvelé tout seul), règle la configuration de production et démarre le service. On peut la relancer sans rien perdre. Le script est lisible ici : deploy/install.sh.

    Je préfère trois commandes, sans curl 
    sudo apt update && sudo apt install -y git
sudo git clone {{REPO}}.git /opt/dynamite_agile
sudo bash /opt/dynamite_agile/deploy/install.sh atelier.mon-domaine.ca moi@exemple.ca
  5. Ouvrez l'outil et créez votre équipe Ouvrez https://atelier.mon-domaine.ca, compte admin et le mot de passe affiché ; choisissez le vôtre. Puis ⚙ Admin → Comptes → Règles d'accès, une ligne par personne, et ⚙ Admin → Spaces pour le Space du projet. Le guide vous accompagne.

  4. Ouvrez le tunnel, depuis votre ordinateur Dans un nouveau terminal sur votre ordinateur (laissez-le ouvert pendant l'essai) : 
    ssh -N -L 8080:127.0.0.1:8080 root@203.0.113.10

    Le terminal semble figé : c'est normal, le tunnel est ouvert. Ouvrez http://127.0.0.1:8080, compte admin / admin, avec l'équipe d'exemple. Pour passer en ligne plus tard, refaites le parcours « Sur un serveur en ligne ».

  1. Choisissez le PC qui héberge l'outil Windows 10, 11 ou Server 2019 et plus, branché au réseau de l'équipe et toujours allumé (Paramètres → Système → Alimentation : mise en veille Jamais). Le réseau doit être marqué Privé (Paramètres → Réseau et Internet → Propriétés), sinon le pare-feu bloque l'équipe.
  2. Ouvrez PowerShell en administrateur Sur ce PC : Win + X → Terminal (admin) (ou Windows PowerShell (admin)), puis Oui.

    La ligne commence par PS C:\WINDOWS\system32> : vous êtes administrateur.

  3. Installez, en une commande 
    irm {{SITE_URL}}/install.ps1 -OutFile $env:TEMP\install-dynamite.ps1; powershell -ExecutionPolicy Bypass -File $env:TEMP\install-dynamite.ps1

    Cinq à dix minutes. La fin affiche == C'est installé, l'adresse à ouvrir (https://nom-du-pc et son adresse IP) et le mot de passe temporaire du compte admin : gardez cette fenêtre ouverte.

    Ce que fait la commande

    Elle installe Python 3.12 et Git (winget), récupère le code dans C:\DynamiteAgile, crée l'autorité de certification de l'équipe et le certificat HTTPS de ce PC, règle la configuration de production, ouvre le port 443 pour les réseaux privés seulement, et crée la tâche « Dynamite Agile » qui démarre avec Windows et relance l'outil s'il s'arrête. On peut la relancer pour mettre à jour, sans rien perdre. Le script est lisible ici : deploy/install.ps1.

    Port 443 déjà pris, ou un autre dossier 
    powershell -ExecutionPolicy Bypass -File $env:TEMP\install-dynamite.ps1 -Port 8443 -Dossier D:\DynamiteAgile

    L'adresse devient alors https://nom-du-pc:8443.

  4. Faites confiance au certificat, sur chaque poste Le script a créé C:\DynamiteAgile\data\tls\partage\ca-dynamite.crt. Copiez ce fichier sur chaque poste de l'équipe (clé USB, dossier partagé, courriel). Sur un poste Windows, dans PowerShell (pas besoin d'être administrateur), dans le dossier du fichier : 
    Import-Certificate -FilePath .\ca-dynamite.crt -CertStoreLocation Cert:\CurrentUser\Root

    Windows demande de confirmer l'autorité « Dynamite Equipe Root CA » : Oui. Sur macOS : double-cliquez le fichier, puis Trousseau → Toujours approuver. Sous Linux : Firefox ou Chrome → Paramètres → Certificats → Autorités → Importer.

  5. Ouvrez l'outil et créez votre équipe Depuis n'importe quel poste, ouvrez https://nom-du-pc (ou https:// + l'adresse IP affichée), compte admin et le mot de passe temporaire ; choisissez le vôtre. Puis ⚙ Admin → Spaces → Commencer, ou ⚙ Admin → Comptes → Règles d'accès. Le guide vous accompagne.
