L'appliquer, en trois gestes

  1. TéléchargerLe paquet ci-dessus, sur votre ordinateur. Un seul fichier, même si votre portail a plusieurs versions de retard : il contient toute la série.
  2. VérifierDans le portail : ⚙ Admin → Update et sauvegardes → Framework → « Vérifier un zip de mise à jour… ». Le portail contrôle que chaque fichier est bien celui du paquet publié, affiche son empreinte SHA-256 (comparez-la avec celle d'ici) et les fichiers que quelqu'un aurait modifiés à la main sur votre serveur.
  3. Approuver ou attendreUne étape par version apportée, avec ses changements ; tout approuvé → « Appliquer » : le portail garde une copie du code et un point de restauration des données, puis redémarre (environ 10 secondes). « Plus tard » ne change rien, et « Revenir à la … » reprend le code d'avant si besoin.
Installé avec la commande d'installation (VPS Linux ou PC Windows) ? Relancer la même commande met aussi à jour, sans toucher aux données ; les deux façons peuvent se suivre.
