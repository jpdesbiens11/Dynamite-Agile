Apply it, in three moves

  1. DownloadThe package above, on your computer. One file, even if your portal is several versions behind: it holds the whole series.
  2. CheckIn the portal: ⚙ Admin → Update et sauvegardes → Framework → « Vérifier un zip de mise à jour… ». The portal checks that every file is the one of the published package, shows its SHA-256 (compare it with the one here) and the files someone may have edited by hand on your server.
  3. Approve or waitOne step per version it brings, with its changes; all approved → « Appliquer »: the portal keeps a copy of the code and a restore point of the data, then restarts (about 10 seconds). « Plus tard » changes nothing, and « Revenir à la … » brings the previous code back if needed.
Installed with the installation command (Linux VPS or Windows PC)? Running the same command again also updates, data untouched; both ways can follow each other.
