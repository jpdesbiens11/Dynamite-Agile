Steps done: 0
  1. Prepare the server A Linux VPS running Ubuntu 24.04 (1 vCPU and 1 GB of memory are enough). In your host's control-panel firewall, open ports 22, 80 and 443.
    Where to find this at Hostinger
    • hPanel → VPS → OS & Panel: system Ubuntu 24.04 (with no application using ports 80 or 443).
    • Overview page: the server IP, the SSH user root, and Root password → Change to set the password.
    • Security → Firewall: allow 22, 80 and 443.
  2. Point the domain to the server In the domain's DNS manager, create an A record: name workshop (or @), value 203.0.113.10. Check a few minutes later: 
    nslookup workshop.my-domain.com

    You should see 203.0.113.10 in the answer. If not, wait a little longer.

    At Hostinger

    hPanel → Domains → your domain → DNS / Nameservers, or Claim your free domain on the VPS page.

  3. Log in to the server Open a terminal (Windows: Terminal or PowerShell; macOS: Terminal) and type the root password when asked (nothing shows while you type, that's normal): 
    ssh root@203.0.113.10

    The line now starts with root@…: you are on the server. On the first connection, answer yes. No terminal? The Web console button of the control panel does the same.

  4. Install, with one command 
    curl -fsSL {{SITE_URL}}/install.sh | sudo DA_LANG=en bash -s -- workshop.my-domain.com me@example.com
    curl -fsSL {{SITE_URL}}/install.sh | sudo DA_LANG=en bash -s -- --traefik workshop.my-domain.com

    Not sure about Traefik? The command detects it by itself and installs behind it. To update later: run the same command again, the data stays.

    Two to five minutes. The end shows == 7/7 Installed, the address to open and the temporary password of the admin account: keep this window open.

    What the command does

    It fetches the code into /opt/dynamite_agile, installs Python, git, certbot and the firewall, creates the dynamite system user, obtains the HTTPS certificate (renewed automatically), sets the production configuration and starts the service. You can run it again without losing anything. You can read the script here: deploy/install.sh.

    I prefer three commands, without curl 
    sudo apt update && sudo apt install -y git
sudo git clone {{REPO}}.git /opt/dynamite_agile
sudo DA_LANG=en bash /opt/dynamite_agile/deploy/install.sh workshop.my-domain.com me@example.com
  5. Open the tool and create your team Open https://workshop.my-domain.com, account admin with the password shown; choose your own. Then ⚙ Admin → Comptes → Règles d'accès, one line per person, and ⚙ Admin → Spaces for the project's Space. The guide walks you through it.

  1. Choose the PC that hosts the tool Windows 10, 11 or Server 2019 and later, plugged into the team's network and always on (Settings → System → Power: sleep Never). The network must be marked Private (Settings → Network & internet → Properties), otherwise the firewall blocks the team.
  2. Open PowerShell as administrator On that PC: Win + X → Terminal (Admin) (or Windows PowerShell (Admin)), then Yes.

    The line starts with PS C:\WINDOWS\system32>: you are administrator.

  3. Install, in one command 
    irm {{SITE_URL}}/install.ps1 -OutFile $env:TEMP\install-dynamite.ps1; $env:DA_LANG = "en"; powershell -ExecutionPolicy Bypass -File $env:TEMP\install-dynamite.ps1

    Five to ten minutes. The end shows == Installed, the address to open (https://pc-name and its IP address) and the temporary password of the admin account: keep this window open.

    What the command does

    It installs Python 3.12 and Git (winget), fetches the code into C:\DynamiteAgile, creates the team's certificate authority and the HTTPS certificate of this PC, sets the production configuration, opens port 443 for private networks only, and creates the « Dynamite Agile » task that starts with Windows and restarts the tool if it stops. Run it again to update, nothing is lost. The script is readable here: deploy/install.ps1.

    Port 443 already used, or another folder 
    powershell -ExecutionPolicy Bypass -File $env:TEMP\install-dynamite.ps1 -Port 8443 -Dossier D:\DynamiteAgile

    The address then becomes https://pc-name:8443.

  4. Trust the certificate, on each computer The script created C:\DynamiteAgile\data\tls\partage\ca-dynamite.crt. Copy this file to each computer of the team (USB key, shared folder, email). On a Windows computer, in PowerShell (no administrator needed), in the folder of the file: 
    Import-Certificate -FilePath .\ca-dynamite.crt -CertStoreLocation Cert:\CurrentUser\Root

    Windows asks to confirm the « Dynamite Equipe Root CA » authority: Yes. On macOS: double-click the file, then Keychain → Always Trust. On Linux: Firefox or Chrome → Settings → Certificates → Authorities → Import.

  5. Open the tool and create your team From any computer, open https://pc-name (or https:// + the IP address shown), account admin and the temporary password; choose yours. Then ⚙ Admin → Spaces → Commencer, or ⚙ Admin → Comptes → Règles d'accès. The guide walks you through.
