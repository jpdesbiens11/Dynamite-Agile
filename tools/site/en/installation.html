Before you start: where are you installing from?

The computer on which you type the commands (the one showing this page). It is not necessarily where the tool will run: that is step 1. Every « on your computer » command follows this choice.

0 steps done

  1. 1 Where will the tool run?

    Need help? An AI assistant guides you step by step

    Open Claude (or your usual assistant) and paste this message: it reads this page and guides you one command at a time. Then paste what the screen shows, especially a red message. For a server that is not empty (other applications, Docker…) or with no Internet at all, it adapts the procedure.

    Never give it a password or a private key: those are typed only in the terminal.

  2. 2 Get a server (VPS)

    An empty server running Ubuntu 24.04: 1 CPU and 1 GB of memory are enough. Choose a host:

    1. On hostinger.com, take a VPS plan (the smallest is enough).
    2. hPanel → VPS → OS & Panel: Ubuntu 24.04, the plain system (no panel, no application).
    3. Overview page: note the IP address; Root password → Change to choose the password.
    4. Security → Firewall: if there are rules, allow ports 22, 80 and 443.
    1. On oracle.com/cloud/free, create a « Free Tier » account.
    2. Compute → Instances → Create instance: image Canonical Ubuntu 24.04, shape VM.Standard.A1.Flex (or VM.Standard.E2.1.Micro if the other is unavailable), both « Always Free ».
    3. While creating it, Save private key: keep this .key file in your Downloads folder, it replaces the password.
    4. Instance page → Subnet → Security List → Add Ingress Rules: source 0.0.0.0/0, TCP, port 80 then 443. Note the public IP address.
    1. On digitalocean.com (students: first activate the GitHub Student Developer Pack), Create → Droplets.
    2. Image Ubuntu 24.04, the smallest plan, password authentication (choose it).
    3. Note the Droplet's IP address. No firewall to set: the installation takes care of it.

  3. 3 Give it a web address

    The team will open the tool at an address like workshop.my-domain.com, over HTTPS. In the domain's DNS manager, create an A record: name workshop, value 203.0.113.10.

    At Hostinger, nothing to set: your VPS already has a free name (hPanel → VPS → Overview → Hostname, e.g. srv123456.hstgr.cloud) that points to its IP address. Use it as is, or with a word in front: workshop.srv123456.hstgr.cloud.

    No domain name?
    • At Hostinger: the VPS's free name, above. Or buy a domain (about ten dollars a year).
    • Free: a DuckDNS subdomain (my-team.duckdns.org): sign in, choose the name, paste the IP address, update ip.

    Check a few minutes later, in a terminal ():

    nslookup workshop.my-domain.com

    The answer must show 203.0.113.10. Otherwise, wait a little longer.

  4. 4 Connect to the server

    Open a terminal on your computer () and type:

    ssh root@203.0.113.10

    Once, protect the downloaded key (otherwise the connection refuses it):

    icacls $HOME\Downloads\ssh-key.key /inheritance:r /grant:r "$($env:USERNAME):(R)"
    chmod 600 ~/Downloads/ssh-key.key

    Then connect:

    ssh -i $HOME\Downloads\ssh-key.key ubuntu@203.0.113.10
    ssh -i ~/Downloads/ssh-key.key ubuntu@203.0.113.10

    The file has another name? Replace ssh-key.key with it.

    Answer yes the first time, then type the password if asked (nothing shows, that's normal). The line now starts with root@… or ubuntu@…: you are on the server. No terminal? The host's Console button does the same.

  5. 5 Install, in one command

    curl -fsSL {{SITE_URL}}/install.sh | sudo DA_LANG=en bash -s -- workshop.my-domain.com me@example.com

    Two to five minutes. The end shows == 7/7 Installed, the address and the temporary password of the admin account. Open https://workshop.my-domain.com, sign in, choose your password, then ⚙ Admin → Spaces → Commencer to create your product's Space with AI.

    What the command does

    It installs Python, git, certbot and the firewall, fetches the code into /opt/dynamite_agile, gets the HTTPS certificate (renewed automatically) and starts the service. To update later: ⚙ Admin → Update, or run the same command again; the data stays. The script is readable here: deploy/install.sh.

  6. 2 Choose the team PC

    Windows 10, 11 or Server, on the team's network and always on (Settings → System → Power: sleep Never). The network must be Private (Settings → Network & Internet → Properties). Internet is needed during the installation only.

  7. 3 Open PowerShell as administrator

    On this PC: Win + X → Terminal (Admin), then Yes.

    The line starts with PS C:\WINDOWS\system32>.

  8. 4 Install, in one command

    irm {{SITE_URL}}/install.ps1 -OutFile $env:TEMP\install-dynamite.ps1; $env:DA_LANG = "en"; powershell -ExecutionPolicy Bypass -File $env:TEMP\install-dynamite.ps1

    Five to ten minutes. The end shows == Installed, the address (https://pc-name) and the temporary password of the admin account.

    What the command does

    It installs Python and Git, fetches the code into C:\DynamiteAgile, creates the team's HTTPS certificate, opens port 443 for the private network only and creates the task that starts the tool with Windows. The script: deploy/install.ps1.

  9. 5 Open the tool on each computer

    Once on each other computer of the team (the team's PC already trusts it: the installation took care of it):

    1. Copy the file C:\DynamiteAgile\data\tls\partage\ca-dynamite.crt from the team's PC (USB key, shared folder) into the computer's Documents folder.
    2. Open a terminal on this computer (). No need to move to a folder: the command looks for the file in Documents.
    3. Paste this command, then Enter:
    Import-Certificate -FilePath (Join-Path ([Environment]::GetFolderPath("MyDocuments")) "ca-dynamite.crt") -CertStoreLocation Cert:\CurrentUser\Root
    sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Documents/ca-dynamite.crt
    sudo cp ~/Documents/ca-dynamite.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates

    On Windows, the command finds Documents even when it is synced with OneDrive. Firefox has its own certificates: Settings → Certificates → Authorities → Import, then pick the file in Documents.

    Open https://pc-name, account admin and the temporary password, then ⚙ Admin → Spaces → Commencer.

From the installation: the DEMO Space

The tool opens on a single Space, DEMO: the guided tour of every tool, a sandbox where everything can be tried risk-free, the training documents and the reference library. It also holds a complete example, the Rover: a small autonomous robot built on an all-terrain RC car, driven by a Raspberry Pi and a web app, that slows down near an obstacle and goes around it slowly. Every module is filled from MVP 0 to MVP 3: needs and requirements, Test Base, function tree, structure, parts, risks and DFMEA, backlog, ideation, Pugh, Kepner-Tregoe, deliverables, PDP plan and pages that explain every decision.

  1. ExploreDynamite → DEMO → « Rover — accueil du projet »: the reading guide says where to look, module by module.
  2. Start your project⚙ Admin → Spaces → Commencer: an AI assistant prepares your product's Space.
  3. Hide DEMOWhen the real project starts, ⚙ Admin → Spaces → DEMO → « Cacher pour tous ». The Help documentation stays available.
