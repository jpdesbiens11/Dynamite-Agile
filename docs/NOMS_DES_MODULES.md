# Pourquoi ces noms ? La mine de Dynamite | Agile

Les modules portent des noms de mine. Concevoir un produit, c'est un peu exploiter un gisement : on prospecte, on
dégage la roche, on extrait ce qui a de la valeur, on en vérifie la teneur, puis on l'achemine jusqu'au client. Les
analogies ci-dessous servent à retenir le rôle de chaque outil ; elles sont reprises dans Help (FAQ) et sur le site.

| Module | Dans la mine | Dans le projet |
|---|---|---|
| **Dashboard** | La salle de contrôle du chantier : tous les indicateurs au même endroit. | Tout ce qui vous attend dans tous vos Spaces : tickets, requirements, heures, messages. |
| **Exploration** | La prospection : on étudie le terrain et on planifie où creuser, dans quel ordre, avec quels moyens. | Le plan du projet sur plusieurs mois : phases, jalons, prédécesseurs, Gantt. |
| **Goldmine** | Le filon d'or : ce qu'on est venu chercher, et qu'on trie pépite par pépite. | Les besoins des parties prenantes et les requirements « en or », tracés jusqu'à leur essai. |
| **Dynamite** | La charge qui fait sauter la roche : on dynamite le savoir brut pour le dégager, l'ordonner et le rendre utilisable. | Le wiki de l'équipe : notes, comptes rendus, procédures, décisions, base de connaissances. |
| **Agile** | Les équipes de forage qui travaillent par quarts : chacun sait quel front attaquer cette semaine. | Backlog, sprints et Board ; Change Management (PR, bugs, ECN) quand la galerie dévie. |
| **Testing** | L'essai du minerai (le laboratoire d'analyse) : on mesure la teneur avant de déclarer le filon rentable. | La Test Base, les procédures et les plans d'essai qui prouvent chaque requirement. |
| **Tools** | La boîte à outils du mineur : pic, pelle, et les bons instruments pour chaque roche. | Les méthodes de conception (idéation, Pugh, Kepner-Tregoe) et Generator. |
| **Generator** | Le poinçon des lots : chaque wagon sorti reçoit son numéro, jamais réutilisé. | Le nom, le numéro et le dossier de chaque document du PDP (MIP, CdCF, RC, RVE…). |
| **Timesheet** | Le carnet de quart (le pointage) : qui a travaillé à quel front, combien d'heures. | La feuille de temps par étape du PDP, les vacances, les réclamations de financement. |
| **Training** | L'école de la mine : on apprend les gestes avant de descendre. | Les topics, les tests et les plans de formation. |
| **Help & HeadLamp** | La lanterne : elle éclaire la galerie juste devant vous. | Le tour du site pas à pas et le Space bac à sable HEADLAMP pour s'exercer sans risque. |
| **Audit** | L'inspection de la mine : on signale ce qui menace la sécurité ou le rendement. | Les observations sur l'outil lui-même, planifiées dans une révision. |
